UPSKILL — Quiz Integrity Verification Patch v2

IMPORTANT FIX IN V2:
The previous patch accidentally omitted the existing quiz timer block from
resources/views/student/courses/enrollment.blade.php. Because hideAllViews()
references _quizTimerId, that omission caused a JavaScript ReferenceError when
a student opened a lesson. The result was a blank lesson area and missing
Start Learning / Mark Complete / Continue behavior.

V2 restores the original quiz timer and auto-submit functions while retaining
the quiz-integrity changes.

Main integrity changes retained:
- Quiz answers are submitted, not a client-supplied score.
- Server-side grading determines correct count and pass/fail.
- Correct answers are not included in student QUIZ_DATA.
- Quiz attempt answer evidence is persisted server-side.
- Legacy completion bypass is neutralized.
- Stacking approval requires pending_approval.
- Academic-credit recognition synchronizes live stacking progress.
